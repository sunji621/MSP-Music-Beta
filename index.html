附近的手机（双向互通）
在手机版「局域网」页开启「本机共享」后，这里会发现手机，输入手机屏幕上的配对码即可浏览、播放手机里的歌曲。

连接不上？
  • 手机与电脑必须连接同一个 WiFi / 路由器
  • Windows 首次开启会弹防火墙提示，请勾选「专用网络」并允许访问
  • 部分路由器开启了「AP 隔离」，需在路由器管理页关闭，或在手机端手动输入电脑地址
  • 公司 / 校园网络常限制设备互访，建议改用手机热点测试

你的本地音乐世界。自动匹配封面与歌词、个性化背景与透明度、系统托盘后台播放——花一分钟完成初始设置吧。

选择你喜欢的主题

可以随时在「设置 → 个性化」中切换，设置后立即生效。

添加你的音乐文件夹

选择存放音乐的文件夹，MSP Music 会自动扫描其中的歌曲并匹配封面、歌词。可以添加多个，也可以稍后再设置。

关闭主窗口时？

选择点击右上角关闭按钮时的行为，之后可在「设置 → 播放设置」中修改。
